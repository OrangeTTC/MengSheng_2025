# 二维云台舵机控制系统

## 系统概述

本系统实现了基于STM32H7的二维云台控制功能，通过USART3串口接收控制命令，控制两个舵机（地址2和3）的位置。

## 硬件配置

- **主控**: STM32H750VBTx
- **舵机数量**: 2个
  - 舵机1地址: 2
  - 舵机2地址: 3
- **通信接口**:
  - USART3: 接收舵机控制命令（波特率115200）
  - UART4: RS485总线，与舵机通信

### 模块说明

#### 1. Connect 模块 (Connect.c/h)
- **功能**: 处理USART3串口接收和命令解析
- **特性**:
  - DMA不定长数据接收
  - 命令帧校验
  - 自动识别帧头和计算校验和

#### 2. Control 模块 (Control.c/h)
- **功能**: RS485舵机控制协议实现
- **特性**:
  - CRC16校验
  - 支持多种舵机控制命令
  - 绝对/相对位置控制
  - 速度控制
  - 开环控制

## 命令协议

### USART3 接收命令格式

```
M[ID][±][AAAA]
```

**字段说明:**
- **M**: 命令头（固定字符）
- **ID**: 电机地址（'2' 或 '3'）
- **±**: 符号位（'1' = 正，'0' = 负）
- **AAAA**: 4位位置值（0000-9999）

**示例:**
- `M210500` - 电机2移动到位置+500
- `M301000` - 电机3移动到位置-1000
- `M210000` - 电机2移动到原点(0)

详细协议说明请参考：[USART3_Command_Protocol.md](USART3_Command_Protocol.md)

## 使用方法

### 1. 编译与下载

使用Keil MDK或其他支持的IDE编译项目，然后下载到STM32开发板。

### 2. 硬件连接

1. 连接USART3到上位机（USB转串口模块）
2. 连接UART4到RS485收发器
3. RS485总线连接舵机
4. 确保电源供应充足

### 3. 测试


1. 配置串口：115200, 8N1
2. 选择"**文本发送**"模式（ASCII）
3. 发送命令（例如：`M210500`）

## 代码说明

### 初始化流程

```c
// main.c 中的初始化代码
void setup() {
    // 1. 初始化串口
    MX_USART3_UART_Init();  // 控制命令接收
    MX_UART4_Init();         // RS485通信
    
    // 2. 启动DMA接收
    HAL_UARTEx_ReceiveToIdle_DMA(&huart3, usart3_rx_data, sizeof(usart3_rx_data));
    __HAL_DMA_DISABLE_IT(huart3.hdmarx, DMA_IT_HT);
    
    HAL_UARTEx_ReceiveToIdle_DMA(&huart4, rx_data, sizeof(rx_data));
    __HAL_DMA_DISABLE_IT(huart4.hdmarx, DMA_IT_HT);
    
    // 3. 设置舵机原点（可选）
    RS485_SetOrigin(0x01, 0x01);
    RS485_SetOrigin(0x02, 0x02);
}
```

### 中断处理流程

```c
// Connect.c 中的中断回调函数
void HAL_UARTEx_RxEventCallback(UART_HandleTypeDef *huart, uint16_t Size)
{
    if (huart->Instance == USART3)
    {
        // 1. 处理接收到的命令
        ProcessServoCommand(usart3_rx_data, Size);
        
        // 2. 重新启动接收
        HAL_UARTEx_ReceiveToIdle_DMA(&huart3, usart3_rx_data, sizeof(usart3_rx_data));
        __HAL_DMA_DISABLE_IT(huart3.hdmarx, DMA_IT_HT);
    }
}
```

## 注意事项

1. **位置范围**: 
   - 命令中的位置值为4位数字（0000-9999）
   - 加上符号位，实际范围为 -9999 到 +9999
   - 实际运动范围取决于舵机编码器分辨率和机械限位

2. **命令格式**:
   - 命令总长度固定为7个ASCII字符
   - 位置值必须是4位数字，不足补0（例如：5应写成0005）
   - 示例: `M210005` 表示电机2移动到+5

3. **通信稳定性**:
   - 连续发送命令时建议添加延时（至少100ms）
   - 确保RS485总线终端电阻正确配置

4. **错误处理**:
   - 无效的命令头（非'M'）将被忽略
   - 无效的电机ID（非'2'或'3'）将被忽略
   - 无效的符号位（非'0'或'1'）将被忽略
   - 位置包含非数字字符将被忽略

5. **电源要求**:
   - 确保舵机电源充足，避免电压波动
   - STM32和舵机建议使用独立电源，共地

## 故障排查

| 问题 | 可能原因 | 解决方法 |
|------|---------|----------|
| 舵机无响应 | 串口未连接/配置错误 | 检查串口连接和波特率 |
| 命令无效 | 格式错误 | 验证命令是7个字符，格式为M[ID][±][AAAA] |
| 位置错误 | 位置字段不是4位数字 | 确保位置是4位（如5写成0005） |
| 舵机运动异常 | 位置值超出范围 | 调整位置参数到-9999~9999 |
| RS485通信失败 | 总线配置错误 | 检查终端电阻和接线 |
